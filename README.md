# code_for_MINI
 
Code for the BMM150 magnetometer array system.

|---|---|
| `firmware_for_nrf52832.zip` | nRF52832 firmware for sensor data acquisition and BLE transmission |
| `Data_training_prediction.zip` | Python scripts for data preprocessing, model training, and real-time prediction |
